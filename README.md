# Jm2PDF v2.4.1 - jmcomic本子探索、在线浏览与下载工具 📚

一个开源免费的jmcomic本子探索、下载与 PDF 合并工具，支持关键词搜索、账号登录、收藏夹、批量操作和邮件推送。

## ✨ 特性

### 功能说明

- **本子探索**：支持按关键词搜索，范围可选全部、作品、作者、标签、角色，支持 `+包含` `-排除` 语法；结果可按日期筛选与排序。
- **本子详情**：展示大封面与详细信息，提供「跳转官网」「直接下载」「加入下载列表」「浏览」操作；进入页面自动加载前 5 页预览。
- **在线浏览**：详情页点「浏览」即可直接翻页阅读，无需下载；支持横式/竖式切换，显示当前页/总页数。
- **账号登录**：顶栏「账号」入口，登录后可查看头像、昵称、等级称号、经验进度、收藏数与 J 币；
  账号密码在本机加密保存（AES-256-GCM，与本机标识绑定），磁盘上不出现明文。
- **收藏夹**：账号页可预览收藏（折叠式），收藏页支持按收藏夹筛选与翻页；
  本子详情页可「收藏 / 取消收藏」，收藏时选择要加入的收藏夹。
- **每日签到**：账号页一键签到，弹窗展示签到状态、当月签到天数、连续天数与当天奖励。
- **下载队列**：输入多个 ID（逗号或空格分隔）一次加入队列排队下载，不再有「一次只能跑一批」的限制。
- **任务中心**：每个任务显示状态、页数进度、下载速度与剩余时间；支持单条 暂停 / 继续 / 取消 / 重试，
  以及 暂停全部 / 继续全部 / 清空已完成；可按状态筛选、按名称或 ID 搜索、按进度等排序。
- **断点续传**：暂停或中断的任务继续时，已下好的图片会自动跳过；关窗后队列保留，下次启动可继续。
- **合并 PDF**：可选将每个章节合并为 PDF 文件，通过「生成 PDF」开关自由控制。
- **PDF 元数据**：生成 PDF 时自动写入标题、作者、标签、ID、页数、章节等信息。
- **资源管理器**：按漫画归组浏览本地下载目录，支持批量打开或删除；选中 PDF 时右侧展示元数据。
- **本地浏览**：选中已下载的 PDF 或图片文件夹后点「浏览」，即可在软件内直接阅读。
- **邮件推送**：支持将生成的 PDF 通过邮件发送（兼容 QQ、163 等主流邮箱）。
- **可配置性**：自定义下载目录、并发数等，修改后自动同步到配置文件。
- **配置导入导出**：一键导出配置备份，或从文件导入已有配置。
- **多语言**：内置简体中文、繁体中文、英文，切换后立即生效。
- **主题切换**：支持浅色/深色/跟随系统三种外观，默认深色，切换后立即生效。
- **开源共享**：采用 CC BY-NC-ND 4.0 许可证，允许非商用分享。

## 🚀 快速开始

### 方式一：使用预编译版本（推荐）

1. 访问 [Releases](https://github.com/WisadelZ/jm2pdf/releases) 页面
2. 下载最新的 `jm2pdf-v2.4.1.exe`
3. 双击运行，输入本子 ID 即可开始使用

### 方式二：从源码构建

```bash
# 克隆仓库
git clone https://github.com/WisadelZ/jm2pdf.git
cd jm2pdf

# 安装依赖
python -m pip install -r requirements.txt

# 运行（调试）
python app.py

# 打包成单文件 exe（内部调用 flet pack）
python build.py
```

## 📖 使用说明

### 基本流程

启动后首页是「探索」页，顶栏的「下载」按钮进入下载页，下载相关操作都在这里
（下载页左上角是返回按钮，可回到首页）：

1. **输入本子 ID**：在"本子 ID"框中输入本子编号（如：`1462837`），多个 ID 用逗号或空格分隔
2. **选择下载目录**：指定保存位置（默认 `./download`）
3. **生成 PDF 开关**：主界面可直接切换是否合并 PDF
4. **配置选项**（折叠面板，可选展开）：
   - 图片并发 / 章节并发 / 同时下载本子数：调整下载速度
5. **点击"加入下载列表"**：ID 会进入下载队列并开始下载，输入框同时清空
6. **看进度**：下载页顶栏右上角进入「任务中心」看每个任务的进度，或展开「下载日志」看详细日志

### 下载队列与任务中心

下载页顶栏右上角的图标进入「任务中心」，队列里每个本子是一个任务：

- 每行显示：本子 ID 与名称、状态（等待中 / 下载中 / 已暂停 / 已完成 / 失败 / 已取消）、进度条、
  页数进度、下载速度与剩余时间
- 单条操作：暂停 / 继续 / 取消 / 重试 / 移除 / 打开文件夹
- 顶栏操作：暂停全部、继续全部、清空已完成；第二行可搜索（本子 ID 或名称）、
  排序（加入顺序 / 本子 ID / 名称 / 进度）与按状态筛选
- **暂停**：点下立即变为「已暂停」，正在下载的那一轮在后台收尾（卡片上会显示「正在收尾…」）；
  继续时已经下好的图片会跳过，不会重新下载
- **取消**：会清掉该任务本次下载的图片与 PDF（移入回收站，可从回收站恢复）。
  以前就存在的旧文件不会被误删；若文件夹里还有这类旧文件，会保留该文件夹并在日志里说明
- **暂停全部**：所有任务立刻暂停；此时加入新任务，新任务会直接开始下载，已经暂停的仍保持暂停
- 关窗时若还有未完成任务会先确认；队列保存在程序目录下的 `queue.json`，
  下次启动可继续（未完成任务显示为「已暂停」）

### 搜索功能

1. 在"搜索 ID"框中输入本子 ID（回车或点击"搜索"）
2. 查看返回的信息（自动换行，无需拖动），末尾附有可点击的网页链接：
   ```
   ID: 567464
   页数: 454 / 章节: 1
   名称: 《明日方舟》官方世界观设定集[大地巡旅]
   标签: 非H, 设定集, 中文
   网页链接 https://18comic.vip/album/567464/
   ```
3. 点击"添加"按钮将其加入下载列表

搜索结果框右侧会同时显示该本子的封面缩略图（3:4）。封面只在内存中展示，不会保存到本地磁盘；
若封面取不到，该处显示一个占位图标，不影响搜索结果与后续操作。

### 探索与本子详情

启动后首页即为探索页，用关键词搜索本子。首次点击搜索前，欢迎语与搜索框位于窗口中央；
搜索框下方的指引文案会告诉你搜索方式。

1. 在顶部搜索框左侧选择搜索方式：全部 / 作品 / 作者 / 标签 / 角色（默认「全部」，
   相当于站内搜索，作品名、作者、标签、角色一起搜）
2. 输入关键词后点击搜索图标（或回车）。关键词支持站内语法：`+词` 表示必须包含、`-词` 表示必须排除，
   例如 `+设定集 -中文`
3. 结果每页 20 个，格子尺寸固定（封面 3:4 + 两行名称，名称悬停可看完整内容），按窗口宽度自动换行；
   页面上下各有一套翻页工具，从哪一头开始看都方便
4. 点击封面可放大查看：背景虚化变暗，点击右上角的关闭按钮还原
5. 点击名称进入「本子详情」页：左上方是大封面，右上方是标题 / 本子 ID / 作者 / 标签 / 点赞数 / 观看数 /
   页数 / 章节数，下方可以「跳转官网」「直接下载」「加入下载列表」「浏览」或「收藏」；
   返回探索页后搜索结果仍然保留

搜索之后搜索框会移到窗口顶部，左上角会出现一个返回按钮：点击即可清空关键词与搜索结果，
回到开屏时的居中界面；搜索框右侧的叉号只清空输入的关键词，已经出来的搜索结果不受影响。

结果上方的翻页栏右侧是排序菜单，按钮上显示当前状态（默认是排序方式「最新」；设了时间筛选后
显示筛选方式，如「本月」）。可切换 最新 / 观看数 / 图片数 / 点赞数，排序由站点服务端完成，
切换后自动回到第 1 页重新加载（客户端没有提供「最旧」这类升序排序）。菜单最后一项是「按日期筛选」，
可再按 今天 / 本周 / 本月 / 全部 缩小范围：点「取消」返回结果页，点「确认」按所选范围重新加载。

时间筛选与其它排序方式互斥：它只在「最新」（按时间排序）下有意义，所以确认时间筛选会把排序
切回「最新」，而选择 观看数 / 图片数 / 点赞数 会自动取消时间筛选。菜单里当前排序方式右侧有勾选标记。

搜索结果与详情里的封面都只在内存中展示，不会保存到本地磁盘。

### 账号、收藏与签到

顶栏的「账号」按钮可打开账号页。未登录时页面中央是账号、密码输入框与登录按钮：

1. 输入站点账号与密码后点「登录」，成功后页面切换为账号信息视图
2. 左上方展示头像与昵称，右侧依次是等级称号、经验进度条与数值、收藏数（已用/上限）与 J 币
3. 下方是折叠式的「收藏列表」：点击标题可展开 / 收起，展开后展示「全部」收藏夹里最靠前的若干本，
   点击封面或名称进入本子详情；点右侧「查看更多」进入完整的收藏页
4. 「签到」按钮执行每日签到，弹窗会显示签到状态、当月签到天数、连续签到天数与当天奖励
5. 「退出登录」删除本机保存的账号信息并回到登录界面

账号与密码由程序**加密保存在程序目录下的 `account.dat`**（AES-256-GCM，密钥与本机标识绑定），
`conf.yml` 与磁盘上都不出现明文；文件拷到其它机器上无法解密。收藏页支持按收藏夹筛选与翻页，
交互与探索页的结果网格一致。收藏相关操作需要先登录。

### 邮件推送（可选）

展开"邮件推送"面板：
1. 打开"启用邮件推送"开关
2. 填写 SMTP 服务器信息：
   - 服务器：`smtp.qq.com`（QQ邮箱）或 `smtp.163.com`（163邮箱）
   - 端口：`465`（SSL）或 `25`（非加密）
   - 发件箱：你的邮箱地址
   - 授权码：邮箱的授权码（不是登录密码！）
   - 收件箱：留空则发给自己
3. 下载完成后会自动发送邮件

### 资源管理器

顶栏的「资源管理器」按钮可打开资源管理器页，用于管理下载目录里已下载的内容：

- 同一本漫画的图片文件夹与 PDF 会折叠归在同一项下（点击展开），单独的 PDF 或图片文件夹则单独列出
- 勾选项目左侧的复选框后，底部「打开」可用系统默认方式打开（PDF 用默认阅读器、文件夹用资源管理器），
  「删除」则把所选项目**移入回收站**（可从回收站恢复，删除前会弹确认框）
- 勾选 PDF 时，右侧边栏展示该 PDF 的元数据：标题、本子 ID、作者、标签、页数、章节序号；
  旧版本生成的 PDF 没有元数据，会提示「该 PDF 没有元数据」
- 列表与边栏数据来自实时扫描，点击「刷新」可重新读取

### 帮助

顶栏的「帮助」按钮可打开帮助页，展示版本号、作者署名、项目地址、分发协议与免责声明；
如遇问题或有功能建议，可通过页面下方的链接前往 GitHub 项目主页提交 Issue。

### 设置

顶栏的「设置」按钮可打开设置页，包含三个分区：

- **配置管理**：导出当前配置到指定文件备份，或从文件导入已有配置（导入后界面立即刷新）
- **外观设置**：浅色 / 深色 / 跟随系统
- **语言设置**：简体中文 / 繁体中文 / English

外观与语言切换后立即生效，无需重启；下载任务进行中时修改语言会在重启后生效。

## ⚙️ 配置说明

首次运行时会自动生成 `conf.yml`，可手动编辑：

```yaml
app:
  download_dir: ./download      # 下载目录
  to_pdf: true                  # 是否合并为 PDF
  thread_image: 30              # 图片并发数
  thread_photo: 16              # 章节并发数
  task_concurrency: 2           # 同时下载几个本子（1~4）
  theme_mode: dark              # 界面主题：light / dark / system（默认深色）
  language: zh_cn               # 界面语言：zh_cn / zh_tw / en

mail:
  enable: false                 # 是否启用邮件
  server: smtp.qq.com           # SMTP 服务器
  port: 465                     # 端口
  sender: ''                    # 发件邮箱
  password: ''                  # 授权码
  receiver: ''                  # 收件邮箱（留空=自己）
```

登录后的站点账号不写入 `conf.yml`，而是加密保存在程序目录下的 `account.dat`（见「账号、收藏与签到」）；
该文件与本机绑定，拷到其它机器上无法解密。凭据处理与安全边界的完整说明见 [SECURITY.md](SECURITY.md)。
